# Unreal AI tools and access

Reviewed 2026-09-23. Vendor-described capabilities below are candidates for an
acceptance trial, not independent quality endorsements or installed connections.

| Tool | Appropriate use | Setup and limits |
| --- | --- | --- |
| Aura | Read/edit Blueprint graphs; project-aware implementation | Use official installer for the chosen OS/engine, then enable plugin. Current docs list Windows UE 5.4–5.8, Apple Silicon macOS UE 5.7–5.8; public source-build compatibility is excluded. Recheck before choosing a version. Verify account, entitlement and connection indicator. |
| Ludus AI | Blueprint generation/analysis and project-aware Unreal assistance | Follow vendor installation and check exact engine/platform support, indexing permissions and account access. Do not infer compatibility from another plugin. |
| Ultimate Engine CoPilot | Candidate for Blueprint, Niagara, Sequencer and GAS workflows | Author's forum lists UE 5.5–5.7 and desktop platforms. Verify current Fab listing and selected feature before purchase/install. Plugin is not bundled here. |
| Fabric AI | Environment/prototyping demonstration reference | Linked demo identified, but current distributable, setup instructions and support matrix not verified. Do not invent an installer or mark connected. |
| Epic Developer Assistant | Official question/documentation and starting-code assistance | Browser assistant; not evidence of local graph-editing access. Page body was unavailable to this review. |
| CodeGPT for UE5 | External C++/Blueprint-oriented advice and coding assistance | Verify editor integration/model account; code awareness alone does not grant binary Blueprint editing. |
| NVIDIA retrieval workflow | Context retrieval for large Unreal C++ codebases | Technical architecture reference, not a one-click graph editor. Requires an indexing/model deployment decision and access; defer until scale justifies it. |
| ElevenLabs | NPC voice and narration prototypes | Use existing TTS workflow, selected voice/model and account/credits. Test one line; it does not create Blueprint logic. |
