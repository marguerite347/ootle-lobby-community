## Capture and render

1. Build the isolated branch with `npm --prefix creator-hub/hub run build`.
2. Start `trivia-fixture.mjs` only if4223 is not already owned. For a fresh take,
   restart only that disposable fixture, never a live preview or user state.
3. Run `node creator-hub/capture/creator-story/capture-continuous-proof.mjs PRIVATE_DIR`.
   Add `--phone` for390x844. The fixture cannot write live rewards or chat.
4. Inspect source frames and `capture.json`. Video and sound use separate clocks;
   verify synchronization after every take instead of reusing old offsets blindly.
