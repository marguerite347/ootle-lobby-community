## AI Sparks ledger

AI Sparks are proposed in-app AI creation credits, not TARI or cash. Start at zero in the isolated demo. Any production multiplier presentation must be checked against the actual fixture before recording; the following is the proposed demo payout, not a claim about current live rules.

| Event | Balance change | Balance |
|---|---:|---:|
| Start | 0 | 0 |
| Trivia jackpot: 150 base × 50 multiplier, credited once | +7,500 | 7,500 |
| First puzzle solved | +50 | 7,550 |
| First Riff | +100 | 7,650 |
| Explicitly confirmed AI improvement | −250 | 7,400 |
| First published game | +200 | 7,600 |

The base and multiplier are a payout calculation, not extra balance deposits. No intermediate amounts are added twice. Overlay/UI balance derives from one ledger file in the eventual composition.
