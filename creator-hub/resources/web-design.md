## Proposed quick-start collections

Curate complete, tested visual recipes: a lit GLB model viewer, an interactive project showcase, a polished game landing page, a responsive inventory/shop UI and a creator profile. Pair code with matching assets, fonts and sample content. Show preview, dependencies, target environment, license, mobile/performance notes and what to replace to make it one's own.

Keep plain HTML/CSS/JavaScript options alongside React-based recipes. Test keyboard access, reduced motion, loading states and mobile rendering. A beautiful screenshot does not establish a reusable or performant template. Link each verified recipe to assets through the [asset catalog design](../ASSET_MARKETPLACE.md).
