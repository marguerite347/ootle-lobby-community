# Godot: complete games to study

[Community announcement](https://www.reddit.com/r/godot/comments/1q2o34p/we_released_24_opensource_games_for_you_to/) and [primary project collection](https://github.com/100-Devs-1-Game/Our-Open-Source-Games). Checked 2026-09-19.

The collection links game repositories, playable itch.io pages and selected Game Design Documents. Use it to inspect complete gameplay loops and how design documents connect to actual projects. Example entries include **Road to Nowhere** (deckbuilder/city-builder), **Paper Town** (turn-based RPG) and **The Full Picture** (detective game). These are upstream descriptions, not claims that the projects have been run or tested here.

The author describes these as games to study rather than polished reusable templates. Their announcement reports MIT code and CC BY-NC-SA 4.0 assets. Verify licenses per game and asset before reuse, especially commercial reuse of noncommercial assets. Record the Godot version, dependencies, source revision and setup instructions. Some projects need Git LFS for assets; the collection flags Paper Town.

This is a discovery collection, not 24 individually validated marketplace listings. Promote games individually only after checking source, demo, license and compatibility. Preserve the announcement as provenance, and use the project repository as the primary artifact source. No current maintenance claim or Tari/Ootle integration is established.
