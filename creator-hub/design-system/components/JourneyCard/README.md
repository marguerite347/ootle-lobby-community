# JourneyCard

Collectible portal card (`.journey`) for the main creator journeys — Discover, Learn, Build, Riff.

Static rendition of the homepage journey portals (`HubMotion.css`). The consumer supplies a `.k` kicker (eyebrow + step), an inline SVG in `.journey-art` (line art in `currentColor`), an `h4`, a `p` and a `.journey-action` row.

- `radius-portal`, padding 22px, `bg-elev` with a faint lavender radial; 4-up grid, 2-up under 1000px.
- Hover/focus lifts 7px, borders in `lavender-glow`, sweeps one shine and animates its art; all off under reduced motion or effects off.
- Headline is expressive, the paragraph says plainly where it goes.
