# Milestone

Celebration toast (`.hub-milestone`) for a real creator milestone — first publish, first Riff.

Static rendition of `.hub-milestone` in `HubMotion.css`. The consumer supplies a glyph, a `strong` headline, a plain `p` and a dismiss button; it sits in a fixed region above the bottom edge, max 480px.

- Purple-to-ink gradient, `lavender-glow` border, `radius-portal`, `shadow-milestone`; the glyph glows `focus` lime.
- Arrives with a short rise (`milestone-arrive`), no animation under reduced motion or effects off. Dismissable; never blocks controls.
