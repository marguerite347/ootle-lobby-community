# Field

Text inputs: the pill `.searchbar` for hero search and `.field` inputs, textareas and selects with a `.lbl` label.

Static rendition of `input.field`, `label.lbl` and `.searchbar` from `styles.css`. The consumer supplies the label text, `id`/`for` pairing and any help text.

- `.field`: `bg-elev-2`, `border-strong`, `radius-sm`, 11×14px, 14px text; focus turns the border `accent-strong` and shows the `focus` ring.
- `.searchbar`: pill input on `bg-elev` beside a primary button, max 620px.
- Labels are 13px `muted`, above the control.
