# Notice

Inline message block (`.notice`) on `accent-dim`, and the `.provenance` note that credits a source.

Static rendition of `.notice` and `.provenance`. The consumer supplies the message. Use a notice for a caveat that matters to the next action (access needed, preview-only, not deployed); keep claims factual.

- `.notice`: `accent-dim` ground, `border-strong`, `radius-sm`, 13px `muted`.
- `.provenance`: 2px `accent-dim` rule on the left, 13px `muted` — source attribution only, not a general card style.
