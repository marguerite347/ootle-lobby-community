# Facet

Filter sidebar (`.filters`) of facet buttons with counts, used beside results in `.with-side` layouts.

Static rendition of `.filters` / `button.facet`. The consumer supplies group headings (`h4`) and facet buttons with a `.n` count.

- Sticky at 84px on desktop; static under 900px.
- Headings: 12px uppercase `faint`, .08em. Facets: 13.5px `muted`; hover `bg-elev-2`; active `accent` on `accent-dim`.
