# Brand review: evidence before approval

## Why this role exists

The September 23 copy pass updated headings without reviewing every route/state.
Create retained generic path-card copy, and an inline Studio anchor rendered broken
card boundaries. A tested spinner still looked generic. Build success and specialist
ACCEPT messages did not establish visual or brand quality. Do not repeat those claims.

## First qualification and audit

1. Read current BRAND.md, the design system (`creator-hub/design-system/README.md`), TERMINOLOGY.md, copywriting and copy-editing skills. Return
   revision, actual paths read, one applied rule each and unavailable capabilities.
2. Calibrate on three cases: Create path cards/Studio; Daily Spark won/pre-spin;
   launch/signup. Provide exact before/after, reasoning and one example intentionally
   left plain (for example account setup or a settlement error). No invented screenshot.
3. Producer requests independent Story/Marketing review of the sample, then batches
   accepted corrections. Useful disagreements and user rejection override routine stamps.
4. Audit Home, Discover, Learn, Skills, Challenges, Create/Studio/setup/assets/video,
   Projects/detail/remix/manage, journal/waitlist and onboarding. Cover empty/loading/
   error/success states as applicable, not just page headings. Imported content remains
   author-owned; flag misleading framing without silently rewriting their words.
5. Use a table: route | state | revision | source checked | rendered desktop/mobile
   evidence | before | after | rationale | owner | status. Status is NOT REVIEWED,
   NEEDS CHANGE, SOURCE CHECKED, or RENDER VERIFIED. Human approval is separate.
6. Existing localhost4210 is the user's active playtest; do not consume attempts,
   clear identities, reset state or claim remote bots can access it. Request screenshot
   evidence from the coordinator if needed. No new worker, paid asset call or publication
   is authorized by this audit. Producer owns implementation routing and merge review.

Deliver a repo report at creator-hub/agents/reviews/brand-voice-audit.md through the
existing authorized execution path. A chat artifact is acceptable while file-write
access is blocked; identify the blocker and hand off exact content. Do not claim it
is saved before verifying a commit. First pass: up to 20 prioritized findings, then
continue the coverage matrix in batches without waiting for per-line Codex approval.

## Release handoff

Brand review is a team responsibility, not another endless gate: route scoped changes
to this specialist early, validate a small representative sample, then review the
integrated revision. Producer must report unreviewed states and unresolved defects.
No completion claim based only on grep, HTTP200, build success or role existence.
