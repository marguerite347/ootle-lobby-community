## Agent onboarding

The root AGENTS.md routes game tasks here. A repo-local `.agents/skills/tari-game-development/SKILL.md` exposes the entry point to compatible clients. Cursor and Claude entry files point to AGENTS.md. Other agents should read AGENTS.md at the start of work; no single configuration can force every agent client to load instructions. Existing sessions should reread it after pulling. No global installation is needed.

## Updating

Fetch upstream to a temporary checkout, inspect the diff against upstream-lock.json, then replace selected vendored files with their supporting references and preserve LICENSE/NOTICE. Refresh the lock hashes and run `python3 scripts/validate-game-skills.py`. Do not run a latest-version auto-installer on every agent start. Keep Tari-specific changes in the local entry point, not hidden vendor edits.

## Relationship to TariSkills

[TariSkills](../creator-hub/TARISKILLS.md) is the separate [native protocol skill library](../creator-hub/skills/README.md) under CH-012, with per-topic validation scope. Game-engine skills complement it; they do not validate contracts, wallet interfaces or protocol claims. Do not publish this imported catalog as verified native TariSkills.

## Audio production

Four pinned MIT bundles in `vendor/audio/` cover Qwen3-TTS production and official ElevenLabs speech, sound effects and music. They are discoverable in the shared catalog and portable agent endpoints. Local voice casting and human listening are separate from technical generation checks; provider keys, plans and output rights are not supplied by a skill bundle. Preserve each bundle's LICENSE and UPSTREAM.json on updates.

The library also includes 62 pinned upstream game-design skills from
`Stanestane/game-design-skills-bundle` at `1868c5635d1937f599ebc918904533e69a194039`.

in every downloadable bundle. This is catalog availability, not automatic agent
installation or a validation of their results. See the Hub's
[resource-list import guide](../creator-hub/hub/RESOURCE_LIST_IMPORTS.md).
